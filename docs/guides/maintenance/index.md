# Maintenance & recovery

*any role*{ .badge .role }

This set sits **beside the chain**. A fault interrupts whichever stage you were in and does not announce which product owns it, so these pages are titled and indexed **by symptom** — never by stage, never by product.

## The contract

| | |
|---|---|
| **Role** | any role |
| **Needs in hand** | a symptom — something the cell is doing, or refusing to do |
| **Produces** | **a cell you can go back to work with** |
| **Session** | may interrupt an open session |
