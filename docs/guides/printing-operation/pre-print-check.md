# Pre-print check

*print operator*{ .badge .role } *per object*{ .badge .freq }

!!! note "Placeholder page"
    A gate is a **self-check**, not a sign-off. Nothing is signed, nothing is filed.
    It exists so one person can confirm the artefact they are about to hand on is
    complete.

## What must be true

- [ ] *The named artefact exists and is the version you think it is.*
- [ ] *Its inputs agree with the cell it is going to.*
- [ ] *The next person can start without asking you a question.*

## If something here fails

Go back one guide. A gate that fails is cheap; a gate that is skipped is not.
