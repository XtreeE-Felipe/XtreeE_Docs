# Read the printing screen — what to watch

*print operator*{ .badge .role } *per session*{ .badge .freq }

During a print, every sub-page of
[Printing control](../../products/control/printing-control.md) shows the usage
rate of each motor and the program data. Read them while the print runs, and
before and after any manual adjustment.

1. Read the [usage rate](../../products/control/printing-control.md#usage-rate)
   of each motor: where its live value (triangle) sits against its nominal value
   (line) and its extremum values (grey rectangle).
2. Read the [program data](../../products/control/printing-control.md#program-data):
   current layer, time left, volume left and progress.
3. Check the [status box](../../products/control/index.md#status-box).

You have read the screen once you can say, for each motor, where its live value
sits between its extremum values, and how much of the program is left.

!!! tip "If something goes wrong"
    **ERRORS** in the status box → [A motor reports an error code](../maintenance/a-motor-reports-an-error-code.md)<br>
    Real flow differs from the assigned flow → [Real flow doesn't match assigned flow](../maintenance/real-flow-doesnt-match-assigned-flow.md)
