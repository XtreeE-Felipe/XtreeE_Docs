# Stage 2 · Program preparation

*print preparer*{ .badge .role }

This stage happens at a desk, often days before anyone is in the cell. It does not hand its output to a colleague — it **files it into a store**, and Stage 3 begins by choosing from that store.

## The contract

| | |
|---|---|
| **Role** | print preparer |
| **Needs in hand** | an xObject, and a base that has already been taught |
| **Produces** | **a printing program + material spec, filed into the program store** |
| **Session** | outside any session |
