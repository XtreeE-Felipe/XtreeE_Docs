# Stage 5 · Session report

*production lead*{ .badge .role }

Outside the session again. Because objects and sessions are many-to-many, the archive is keyed on both: a session record lists the objects it printed, an object record lists the sessions that built it.

## The contract

| | |
|---|---|
| **Role** | production lead |
| **Needs in hand** | printed objects and a closed session log |
| **Produces** | **a production report + an archived session** |
| **Session** | outside any session, reporting on a closed one |
