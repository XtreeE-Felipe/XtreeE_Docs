# Ink

The **INK** page of [XtreeE Control](index.md) logs material data. The procedure
is in
[Log the batch and spreading diameter](../../guides/session-startup/log-the-batch-and-spreading-diameter.md).

| Element | What it does |
|---|---|
| Recipe | Selects the recipe. |
| Batch volume | Defines the batch volume. |
| **NEW BATCH** | Records a new batch. |
| **SEE RECIPE** | Opens the recipe to read or edit it before validating — see [Recipe window](#recipe-window). |
| Recipe summary | The current recipe, computed to match the batch volume. |
| Batch identification number | The number of the current batch. |
| **RESET COUNTER** | Resets the batch identification number. |
| Spreading diameters | Logs the current value and shows it in the graph below, between acceptable values. |

## Recipe window

**SEE RECIPE** opens a pop-up window. Every framed field of the list —
references and quantities — can be edited. Click **SAVE** when finished, or
**CLOSE** to ignore the changes.
